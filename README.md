# 📈 StockSense – AI-Powered Stock Market Trend Analysis

## About the Project
StockSense is a Python-based Data Science and Machine Learning project that analyzes historical stock market data and identifies market trends.

It uses technical indicators and a Random Forest classification model to estimate the direction of the next trading session.

## Features
- Historical stock market data collection
- Stock price visualization
- Simple Moving Average (SMA)
- Exponential Moving Average (EMA)
- Relative Strength Index (RSI)
- Moving Average Convergence Divergence (MACD)
- Bullish and Bearish trend identification
- Random Forest Machine Learning model
- UP/DOWN direction prediction
- Stock comparison and CSV export

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Yahoo Finance (yfinance)
- Scikit-learn

## Machine Learning
The project uses a Random Forest Classifier to classify the next trading session's price direction.

- UP: Next closing price is higher than the current closing price.
- DOWN: Next closing price is equal to or lower than the current closing price.

The model is evaluated using accuracy, precision, recall, F1-score and a confusion matrix.

## Stock Market Data
The initial analysis uses Reliance Industries (RELIANCE.NS).

The project also supports other stock symbols, including TCS.NS, INFY.NS and AAPL.

## How to Run
1. Open Google Colab.
2. Upload the StockSense `.ipynb` notebook.
3. Run the cells in sequential order.
4. View the analysis, visualizations and predictions.

## Project Purpose
This project was developed to explore Data Science, financial data analysis, technical indicators and Machine Learning applications in stock market trend analysis.
